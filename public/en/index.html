Cognition map + grill-me-with-docs

Turn a vague research request into a traceable Context and Goal

Research Quest is an open-source gamified research Skill. It reads project documents first, maps what the user knows and does not yet know, asks one high-value question per turn, and keeps each answer focused. When the task is clear enough, it hands a Frozen Context and an executable Goal to Codex or another agent.

Known–Unknown cognition map

Tracks explicit knowledge, unspoken experience, open questions, and hidden risks. The map decides what to ask next, how much terminology to use, and when to stop interviewing.

grill-me-with-docs

Reads documents and existing Context before asking. It does not repeat questions that the material already answers, and it defaults to one question that can actually change the final Goal.
