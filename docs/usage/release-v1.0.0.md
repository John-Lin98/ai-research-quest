# Research Quest v1.0.0 发布说明

Research Quest 是一个纯前端、公开安全的科研决策闯关 Demo。它用两条各七关的战役，把受控选择、关卡小测、Candidate → Confirmed → Verified 证据迁移、最终考试与可导出的 Codex Goal 串成一个可复查流程。

## 从哪里开始

- 试玩页面：[GitHub Pages](https://john-lin98.github.io/ai-research-quest/)
- 76 秒完整流程：[演示视频](https://john-lin98.github.io/ai-research-quest/research-quest-demo-75s.webm)
- 安装 Skill：[v1.0.0 Release](https://github.com/John-Lin98/ai-research-quest/releases/tag/v1.0.0)

## 使用边界

- 所有案例都是模拟、改编或脱敏内容；不代表真实研究结果。
- 页面不上传、不埋点、不向网络发送输入；交互只停留在当前页面内存中。
- 请不要输入邮箱、密钥、token、私有路径或未公开科研资料。
- 自动演示仅展示状态轨迹，不计入用户正式理解分。

## 本版包含

- 双战役共 14 个可交互关卡，以及每关的时间、任务、目标与认知变化提示。
- 仅由关卡小测和应用证据驱动的 Candidate → Confirmed → Verified 单向认证。
- 透明 rubric 的最终考试、可冻结的 Goal、game-state 与 Goal 的本地 Blob 导出。
- 可安装的 `research-quest` Skill，随附研究、软件和学习三套脱敏 fixture。
